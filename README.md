# Elegance The Family Salon - Website Project

![Elegance The Family Salon Logo](images/unnamed%20(1).webp)

A visually stunning, single-page luxury website for **Elegance The Family Salon**, a premium 4.9-star rated family salon located near Kolkata Airport.

## ✨ Project Overview

The goal of this project was to create an online presence that instantly wows visitors with a high-end, luxurious aesthetic. The website is fully responsive, highly interactive, and designed to drive direct customer engagement through WhatsApp bookings.

## 🎨 Design System

**Theme:** Midnight Gold Opulence
- **Backgrounds:** Deep rich blacks and dark charcoal (`#0D0A0B`, `#120F0A`)
- **Accents:** Luxurious warm gold (`#C9A84C`, `#E8C97A`)
- **Typography:** Playfair Display (Elegant Serifs for Headings) + Inter (Clean Sans-serif for Body)
- **Vibe:** Exclusive, warm, premium, and professional.

## 🚀 Key Features

- **Dynamic Hero Section:** Full-viewport AI-generated cinematic background featuring a custom floating "gold dust" particle animation.
- **Service Menu & Pricing:** Interactive tabs for Women, Men, and Common services, complete with dynamic "Limited Offer" badges (extracted directly from salon price boards).
- **Real Google Reviews:** An auto-scrolling, infinite carousel featuring actual 5-star Google reviews from real customers, complete with avatar initials and timestamps.
- **Smart Opening Hours:** A JavaScript-powered status indicator that checks the user's current day and time to display whether the salon is currently "Open" or "Closed".
- **Gallery Lightbox:** A masonry photo grid showcasing original salon photos and results. Clicking an image smoothly opens a full-screen lightbox.
- **Floating WhatsApp Booking:** A pulsing, always-visible WhatsApp button configured to open a pre-filled booking message directly to the salon's number.
- **Mobile Responsive:** Fully optimized for all screen sizes with a hidden sliding hamburger menu and overflow protection.

## 🛠️ Built With

- **HTML5:** Semantic architecture
- **Vanilla CSS3:** CSS Variables, Flexbox, CSS Grid, Keyframe Animations
- **Vanilla JavaScript (ES6):** Intersection Observer API (scroll animations), Canvas API (particle effects), Date/Time logic.
- **FontAwesome:** Scalable vector icons
- **Google Fonts:** Custom typography

## 🖥️ How to Run

Since this is a static website built with pure HTML/CSS/JS, no server or build process is required.

1. Open the project folder.
2. Double-click on `index.html` to open it in any modern web browser (Chrome, Safari, Edge, Firefox).
3. Ensure you have an active internet connection to load the Google Fonts and FontAwesome icons.
